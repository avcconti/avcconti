## Side projects

### 🎮 Rank Your Games

Rankea tu biblioteca de videojuegos comparándolos de dos en dos. Sin puntuar del 1 al 10:
eliges cuál prefieres y un sistema de rating Elo ordena el resto.

- Comparación por pares con rating Elo — el ranking emerge de decisiones simples
- Catálogo completo vía IGDB (Internet Game Database)
- Sincronización entre dispositivos con Supabase

[**App Store**](https://apps.apple.com/app/id6755431111) · [**rankyourgames.app**](https://www.rankyourgames.app)
